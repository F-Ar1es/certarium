# Contributing

Bug reports, interoperability results, documentation corrections, and feature
proposals are welcome through GitHub issues.

The project is not yet accepting external code contributions. Certarium uses a
dual-licensing model, so a contributor agreement must be reviewed and published
before third-party code can be merged without compromising future commercial
licensing. Do not submit code copied from another project or generated under
terms you cannot grant.

All future coding contributions must pass the repository's evidence-first
workflow described in `AGENTS.md`.
