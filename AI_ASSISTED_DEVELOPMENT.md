# AI-assisted development

Certarium began as a product concept proposed and directed by **Carl Flynn**.
Product scope, priorities, acceptance decisions, and release decisions remain
human decisions made by the project owner.

OpenAI Codex is used as an implementation and verification assistant. Its work
may include code generation, documentation, test design, build automation,
research, and review. AI systems are tools and are not listed as copyright owners
or project maintainers.

The repository makes this collaboration visible through README disclosure,
repository-level `AGENTS.md` instructions, executable specifications, and
evidence reports. Commit messages may use an `AI-Assisted-By: OpenAI Codex`
trailer as provenance metadata. This is disclosure only; it does not claim an
official Codex GitHub identity or transfer authorship and accountability away
from the human committer.

AI-assisted changes are not accepted merely because they compile. This project
uses an evidence-first workflow: an executable specification, failing tests
before implementation, automated checks, real execution, and a reproducible
evidence report. The project owner retains final responsibility for accepting
changes and releases.

Material copied or adapted from third-party projects remains subject to its
original copyright and license. AI assistance does not alter that provenance.
